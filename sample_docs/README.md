# Sample documents

Short, synthetic onboarding guides written for this repository. They describe a
fictional data team and exist only so the demo, tests and retrieval evaluation
have something to search. Replace them with your own team's documents.

Each file starts with front-matter that the metadata filter uses:

```
---
role: data_engineer, data_analyst   # data_scientist | data_engineer | data_analyst | all
level: junior, mid                   # junior | mid | senior | all
topic: pipelines
---
```
